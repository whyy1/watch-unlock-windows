# 解锁规则

- **只有“先离开、再回来”才会解锁。** 锁屏后手表信号低于远离阈值，就记为离开；回到靠近阈值时触发解锁。锁屏后一直待在电脑旁，不会自动解锁，需要照常输入密码。用 Windows 动态锁锁屏时，手表在锁屏前就越过了远离阈值，也算离开，回来就能解锁。
- **无感解锁**（按设备设置，默认开启）：
  - 开启：靠近后立即解锁。
  - 关闭：回来后要动一下键盘或鼠标才解锁。手表一直在近处时，会一直等你操作；再次走远，这次返回就作废。
- **通知**（可选）：解锁后通过 [Bark](https://apps.apple.com/app/id1403753865) 推送一条提醒。通知不参与解锁判断。也可以用自建的 Bark 服务器，填 IP 地址时不校验证书。

## 判断流程

| 锁屏后发生了什么 | 结果 |
| --- | --- |
| 手表一直在近处，没有越过远离阈值 | 保持锁定，输入密码解锁 |
| 越过远离阈值，但没有回到靠近阈值 | 保持锁定 |
| 走远后回来，无感解锁开启 | 立即解锁 |
| 走远后回来，无感解锁关闭，手表仍在近处时有键鼠操作 | 解锁 |
| 走远后回来，无感解锁关闭，没有操作就再次走远 | 这次返回作废，保持锁定 |
