# 使用

1. 按[下载与安装](/download)装好程序，从开始菜单打开 **Watch Unlock**。
2. 打开「设备」页，展开「添加手表」，点「开始配对」（不点的话手表搜不到电脑）。然后在 120 秒内，在**手表**（不是 iPhone）的“设置 → 蓝牙”里，等这台电脑出现后点它，再在电脑右下角弹出的 Windows 配对通知里点「允许」。已经在 Windows 蓝牙设置里配对过的设备，跳过这一步，直接在“Windows 已配对设备”里点「绑定此设备」。
3. 配对成功后，程序会自动开始绑定，并弹出“正在绑定”的窗口。**抬腕让手表亮屏**，放在电脑旁边，最多等 30 秒；手表息屏时广播少，容易超时。绑定要读取 Windows 保存的手表密钥，需要管理员权限：如果弹出 Windows 管理员确认，点「是」（UAC 设为不提示的电脑上不会弹出）。之后调整距离、开关无感解锁、保存密码都不再需要管理员权限。如果没有自动开始，在“Windows 已配对设备”里点「绑定此设备」。配对失败时见[配对排错](/guide/troubleshooting)。
4. 在概览页填写 Windows 账户密码。注意要填账户密码，不是 PIN。
5. 锁屏，走远，再走回来，电脑就会解锁。

::: tip 后台要在运行
解锁靠后台程序完成。如果走回来没有解锁，先按[后台程序](/guide/background)确认后台在运行。
:::

## 调整距离

距离阈值可以在「设备」页的手表卡片里点「配置」调整。RSSI 受遮挡影响很大，建议在自己的环境里试几次再定。

## 合盖使用

笔记本合上盖子、接外接显示器使用的，请在概览页打开「合盖时继续检测手表」。这个开关默认关闭：合盖后程序停止检测手表，开盖后才恢复。
