# 配对排错

Apple Watch 本身不能和 Windows 配对。程序的做法是让电脑临时充当一个蓝牙配件来广播，手表才能在“设置 → 蓝牙”里看到它。所以能否配对，也取决于电脑的蓝牙硬件。配对失败时，界面会显示下面的原因之一：

| 提示 | 处理办法 |
| --- | --- |
| 没有找到蓝牙适配器 | 确认电脑有蓝牙，驱动已安装，没有在设备管理器里被禁用。 |
| 蓝牙已关闭 | 点「打开 Windows 蓝牙设置」，打开蓝牙后重试。 |
| 不支持低功耗蓝牙 | 适配器太旧，需要换一个支持蓝牙 4.0 以上的适配器。 |
| 不支持外设模式 | 不少笔记本自带网卡和 USB 蓝牙适配器不支持充当外设，软件无法绕过，需要换一个支持外设模式（Peripheral role）的 USB 蓝牙适配器。 |
| 配对服务启动失败、广播被中断 | 关掉其他正在使用蓝牙的程序，重新开关一次蓝牙后重试。 |

## 其他常见情况

- **手表上看不到这台电脑**：配对窗口只开 120 秒，过期后重新打开；让手表靠近电脑。仍然看不到时，可以[用 iPhone 检查电脑有没有发出配对广播](#用-iphone-检查配对广播)。
- **配对时 Windows 弹出「为设备配对 · 未知设备 · 连接失败」**：这是 Windows 自己的弹窗，通常是 Windows 蓝牙卡在了上一次没完成的配对上。点「关闭」，在手表的蓝牙列表里忽略这台电脑；Windows 蓝牙设置里如果有残留的旧配对，也一并删除。然后**重启电脑**，再重新点「开始配对」。只关闭再打开蓝牙往往不够。
- **手表显示已连接，但程序没有反应**：大多是漏点了 Windows 右下角的配对通知。开着勿扰或专注模式时通知不会弹出，按 Win + N 打开通知中心查找；过期的话重新打开配对窗口再试一次。
- **平时手表显示“未连接”**：正常。配对只为让 Windows 记下手表的身份密钥，之后程序靠手表自身的蓝牙广播判断距离，不需要保持连接。
- **配对完成后，Windows 偶尔提示手表“连接失败”**：电脑只在配对窗口打开时临时充当蓝牙配件，之后 Windows 或手表再尝试连接时可能失败。解锁不依赖这个连接，所以只要走远再回来仍能正常解锁，就可以忽略这条提示。如果同时出现无法解锁，请按[反馈问题](/guide/feedback#反馈问题)把诊断信息发给开发者。
- **以前配对过**：如果手表已经出现在「设备」页「添加手表」里的“Windows 已配对设备”中，直接点「绑定此设备」，不用重新配对。绑定一直失败时，再在 Windows 蓝牙设置里删除这块手表、在手表的蓝牙列表里忽略这台电脑，然后重新配对。

## 用 iPhone 检查配对广播

手表一直看不到电脑，或者看得到但连不上时，可以用免费的 [nRF Connect](https://apps.apple.com/app/nrf-connect-for-mobile/id1054362403) 判断问题出在电脑还是手表：

1. 在 iPhone 上安装 nRF Connect，打开后允许使用蓝牙。
2. 在程序里点「开始配对」，保持配对窗口打开。
3. 在 nRF Connect 的「Scanner」页下拉刷新，找一条标着「Device Type: Heart Monitor」、名称是电脑名的设备，点开查看。

<img src="/images/nrf-connect-pairing.jpg" alt="nRF Connect 扫描到电脑的配对广播" width="320">

- **扫得到**：电脑的配对广播正常，问题在手表连接这一步，按上面的方法忽略旧配对、重启电脑后再试。信号强度数字越接近 0 越强，手机放在电脑旁边时一般在 -40 到 -60 dBm 之间。
- **扫不到，或者贴近电脑信号仍然很弱**：适配器没有把广播发出去，或者发射太弱。把 USB 蓝牙适配器换到机箱前面板的 USB 2.0 口，或用延长线拉到桌面上，远离 USB 3.0 接口；更新适配器驱动后再试。仍然不行时，换一个其他芯片的蓝牙适配器。
