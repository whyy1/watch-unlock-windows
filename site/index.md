features:
  - title: 走开再回来就解锁
    details: 只有手表先越过远离阈值、再回到靠近阈值，才会解锁。锁屏后一直待在电脑旁，不会自动解锁。
  - title: 无感解锁可以关
    details: 默认靠近后立即解锁；关掉后，回来还要动一下键盘或鼠标才解锁。每块手表单独设置。
  - title: 密钥只存在本机
    details: 账户密码、手表密钥（IRK）、Bark 密钥都用 Windows DPAPI 按当前账户加密保存，不会出现在日志或界面里。
  - title: GitHub 和 Gitee 都能下载
    details: 每个版本的安装包同时发布在 GitHub 和 Gitee，GitHub 打不开时可以从 Gitee 下载。
